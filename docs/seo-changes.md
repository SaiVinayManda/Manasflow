## Validation

Run `npm run seo:generate`, `npm run seo:validate`, `npm run lint`, `npm run typecheck`, and `npm run build`. For rendered checks, start the production server on port 3108, then run `npm run seo:validate-rendered`.

Publication dates are included only where recorded in the editorial catalog; last-modified dates come from Git content history. Verified social profiles were unavailable, so sameAs is omitted. Unknown publication dates and social identities require source evidence.
