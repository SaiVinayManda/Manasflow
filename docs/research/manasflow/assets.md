# Manasflow asset provenance

All original-owner images, fonts, media, logos and SVGs were removed from the served asset tree and retained in quarantine. None is used to construct a replacement asset.

| Asset | Origin / purpose |
| --- | --- |
| `public/brand/mark.svg` | New hand-authored Manasflow monogram; no source logo paths reused. |
| `public/brand/flow-study.svg` | New hand-authored abstract vector illustration; not a client project or work sample. |
| Homepage about graphic | New CSS circles and existing Lucide Asterisk symbol. |
| UI icons | Existing `lucide-react` package; no original-source vector exports. |
| `social-card.svg` / `.png` | Original brand artwork and copy, generated by `scripts/generate-brand-assets.mjs`. |
| `public/favicon.ico`, `favicon-32.png`, `apple-touch-icon.png`, `icon-512.png` | Derived only from the new `mark.svg`. |
| `public/site.webmanifest` | New Manasflow app identity, colours and icon. |
| DM Sans | [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/dmsans), `DMSans[opsz,wght].ttf`; SIL Open Font License retained as `DM-Sans-OFL.txt`. Self-hosted. |
| Instrument Serif | [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/instrumentserif), regular and italic TTF; SIL Open Font License retained as `Instrument-Serif-OFL.txt`. Self-hosted. |

Fonts are loaded through `next/font/local`. The app makes no requests to Google Fonts, source asset hosts, social platforms or media services. The new mark is an original design proposal; trademark clearance and final brand approval remain owner tasks.
